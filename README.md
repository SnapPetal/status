# Thon Becker Status

Public status page for [status.thonbecker.biz](https://status.thonbecker.biz), powered by [Upptime](https://upptime.js.org).

Configuration lives in [`.upptimerc.yml`](./.upptimerc.yml). Setup CI rewrites this README with live status after the first successful run.
